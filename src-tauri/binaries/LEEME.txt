CHD Studio - carpeta de binarios

Windows
-------
Si colocas aqui chdman.exe, la aplicacion lo encontrara sola y el usuario final
no tendra que instalar MAME ni configurar ninguna ruta. Puedes descargarlo con:

    npm run chdman

Linux
-----
El paquete .deb depende de mame-tools, que instala chdman en el PATH. Los
binarios .exe de esta carpeta no se incluyen en el paquete de Linux.
