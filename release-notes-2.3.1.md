# ROMForge Studio 2.3.1 — Popularidad por consola

## Novedades

- Popularidad y tendencia disponibles directamente dentro del catálogo de cada consola.
- Nuevos órdenes «Más descargados» y «Tendencia reciente».
- La pestaña «Tendencias» respeta la consola y categoría seleccionadas.
- PS5 muestra novedades recientes cuando su fuente no publica contadores de descargas.
- Las tarjetas muestran las descargas registradas cuando la fuente ofrece esa métrica.
