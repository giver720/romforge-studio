# ROMForge Studio 2.3.0 — Homebrew Store

Esta versión amplía la Homebrew Store para descubrir, comparar y descargar contenido comunitario para 3DS, Wii, Wii U, Switch, PS Vita, PSP, PS4 y PS5.

- Catálogo remoto con caché local, actualización manual y respaldo sin conexión.
- Fichas con portadas, capturas, descripción, requisitos, licencia y selección de archivos.
- Categorías, orden por novedades y actualización, además de rankings de tendencias globales y por consola.
- Descargas con progreso, velocidad, cancelación, reintento, verificación SHA-256 y paquetes HBAS completos.
- Favoritos, historial, detección de versiones distintas y acceso a la carpeta de destino.
- Validación de URLs HTTPS, rutas de manifiestos y limpieza de archivos incompletos.

Incluye instalador Windows x64, ZIP portable y paquete `.deb` para Ubuntu amd64.
